# Arbiter External Security Review Packet

Review baseline: v0.26 Enterprise Validation Program.

Provide the reviewer: architecture diagram, `THREAT_MODEL.md`, `PEN_TEST_SCOPE.md`, production Terraform plan, OpenAPI schema, tenant/RLS migration scripts, secret-custody design, settlement-control design, webhook signing/replay controls, release-gate output, and a staging account.

A completed review should return a dated report with reviewer identity/company, scope, methodology, findings, residual risks, and an evidence SHA-256. Record only report metadata and its cryptographic fingerprint in Arbiter; keep confidential report contents in the approved secure document system.

**Important:** entering a review artifact in Arbiter does not self-certify Arbiter.
