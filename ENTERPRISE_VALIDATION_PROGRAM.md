# Arbiter Enterprise Validation Program — v0.22–v0.26

The program turns the remaining enterprise-grade gaps into five explicit workstreams.

1. **Cloud deployment (v0.22):** Docker image + AWS reference Terraform for ECS Fargate, Multi-AZ RDS PostgreSQL, S3/KMS, Secrets Manager, CloudWatch, HTTPS ALB and autoscaling.
2. **Resilience validation (v0.23):** deterministic local stress scenarios plus deployed-environment load/DR/failover evidence registry and load probe.
3. **External assurance (v0.24):** hash-pinned registry for independent architecture review, penetration test, production load test, restore drill, failover drill and incident exercise. Registration is not certification.
4. **Shadow pilot (v0.25):** design-partner workflow for real venue contracts with no official settlement mutation.
5. **Reference exchange v2 (v0.26):** play-money complementary YES/NO order matching, positions, settlement, order cancellation, balance conservation and end-to-end audit.

The product remains **NOT_CERTIFIED** until deployed and independent evidence exists.
