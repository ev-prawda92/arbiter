# Settlement Assurance

Arbiter v0.21 converts settlement assurance requirements into executable, hash-pinned evidence. The application can run an adversarial contract suite, freeze untouched holdout datasets, and preserve evaluation records in the audit chain.

## Certification boundary

Internal gates are evidence of software behavior, not independent certification. Before Arbiter can be described as production-certified settlement infrastructure, the project still requires an untouched real-contract holdout supplied independently, external security architecture review, penetration testing, production load/concurrency evidence, production backup/restore and failover drills, and an incident-response exercise.
